# Authorization Capabilities (aka zcap)

This specification defines how Object Capabilities can be deployed in
ways that are compatible with Linked Data systems. The specification 
can be found here:

[Authorization Capabilities](https://w3c-ccg.github.io/zcap-spec/)

## JSON Schema

[json-schema](./json-schema) is a package with an informative JSON Schema that is useful for validating the examples used in zcap-spec.

Install dependencies with `npm -w json-schema install`.

Then validate examples using `./json-schema/validate.ts`.
