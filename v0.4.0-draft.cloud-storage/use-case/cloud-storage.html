This document presents the Cloud Storage Delegation use case for Authorization Capabilities (zcap for short), and two scenarios that realize it. The use case originated in "Linked Data Capabilities" by Webber, Miller at RWOT5, which inspired zcaps.

The same content appears as an appendix of the Authorization Capabilities specification. It is published here on its own so that it can be read and linked to without the rest of the specification.

This document is a use case for Authorization Capabilities, and is informative. It defines no normative requirements of its own. Where this document and the specification disagree, the specification takes precedence.
